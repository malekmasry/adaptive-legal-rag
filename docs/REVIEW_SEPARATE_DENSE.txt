выключает CONDITIONAL_DENSE_MERGE. Слабая лексическая выдача теперь заменяется

Сильная лексическая выдача остаётся. Порог, лимиты, чанки и реранкер прежние.

Сохранены answer_review, его промпт, правила исправлений, лимиты времени,
формат ПСБ и фильтр инъекций из 801a498. Это НЕ вариант «35/100 + только review»:
формат ПСБ и изменённая защита из последнего пуша также остаются.

Отдельно исправлен дефект штатной упаковки: answer_review.py включён в ZIP.
Алгоритм ревью не ужесточается. При сбое проверки прежний готовый ответ
сохраняется, как в исходной ветке.

Проверки упакованного решения с локальным API:
- сильный BM25 остаётся лексическим, слабый использует отдельную dense-ветку;
- ревью реально вызывается и возвращает keep;
- при HTTP 500 от ревью оба готовых ответа сохраняются, CSV полон,
  код завершения процесса 0, повторных вызовов ревью нет.
Отдельные тесты conditional retrieval проверяют независимость пулов кандидатов.
Эти проверки не измеряют качество LLM организаторов. Новый скор неизвестен.
